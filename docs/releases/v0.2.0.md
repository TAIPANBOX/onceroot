onceroot for Omarchy 4.5: the same one-command root for AI agents, now with a
native widget in Omarchy's bar.

On Omarchy, coding agents run in modes that don't stop to ask, and the usual
way to let one do system work is passwordless sudo for a while, which hands
root to everything running as your user. onceroot keeps that switch off: the
agent asks for one exact command, Omarchy's own authentication dialog shows it,
and it runs once.

**New in 0.2.0**

- **A bar widget for Omarchy 4.5** (`taipanbox.onceroot`), built to Omarchy's
  plugin contract. It shows a padlock and the count while requests wait and
  takes no room otherwise; it watches the journal instead of polling. A click
  opens each card with Approve and Reject; Approve opens Omarchy's own dialog
  with the same card, so the widget itself cannot approve anything. English and
  Ukrainian. The package installs it under `/usr/share/onceroot/omarchy-plugin`;
  it is also published for `omarchy plugin add` at
  [TAIPANBOX/onceroot-omarchy](https://github.com/TAIPANBOX/onceroot-omarchy).
- **Docs for Omarchy 4.5**, including a note on its dialog: it paints a
  background behind one line of a long message only, so read the card in the
  widget or in `onceroot review` when a busy window sits behind the dialog.

**Install** the package attached here, then follow the README from step 2:

```sh
gh attestation verify onceroot-0.2.0-1-x86_64.pkg.tar.zst --repo TAIPANBOX/onceroot
sudo pacman -U onceroot-0.2.0-1-x86_64.pkg.tar.zst
```
