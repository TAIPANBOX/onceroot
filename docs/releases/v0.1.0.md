The first release of onceroot: root for an AI coding agent, one approved
command at a time. The agent asks for an exact command, you see it in your
desktop's own authentication dialog, and it runs once. Built for Omarchy first;
any Arch Linux with systemd and polkit works.

**Install** the package attached here, then follow the README from step 2:

```sh
gh attestation verify onceroot-0.1.0-1-x86_64.pkg.tar.zst --repo TAIPANBOX/onceroot
sudo pacman -U onceroot-0.1.0-1-x86_64.pkg.tar.zst
```

Or build it yourself from the tagged source with `scripts/package.sh`, the way
the README shows.

**What is in this set:** the Arch package for x86_64, built with `makepkg` from
this tag with the whole test suite in `check()`; the two binaries it holds;
and `SHA256SUMS`. Every file carries a build provenance attestation from this
repository's release workflow, and the binaries were measured as position
independent, bound at load time, with a RELRO segment.

**Run so far:** the package installed with `pacman` on Omarchy 4.0.6 in a
virtual machine, with approve and reject in Omarchy's own dialog, the bar
module, the review window, a request over ssh and the MCP server; 220 test
runs, 206 scenarios bound to tests, 55 of 55 mutants caught, and CI running the
root tests and the package build on every push.
[docs/measured.md](https://github.com/TAIPANBOX/onceroot/blob/main/docs/measured.md)
has each figure and the command behind it.

**Approval from the phone** is off by default. Its Telegram client and its PIN
and code checks come from rollcall and openwrt-mcp, where they already run
against Telegram; onceroot's flow around them is tested against a stand-in
Telegram server.

**Not run yet:** a fingerprint or security key approval (the VM had neither),
polkit agents other than Omarchy's, and an agent using the skill or the MCP
server on its own.
