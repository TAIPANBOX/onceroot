# onceroot v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A root daemon and CLI that let an AI agent run one person-approved command as root, approved at the desk through polkit or, opt-in, from a phone through Telegram with PIN and TOTP, with every step in a signed journal.

**Architecture:** `oncerootd` (root, systemd) owns every decision: it takes requests on a Unix socket, builds the card from the argv itself, applies rules, holds the card, asks polkit with `pkcheck` (and Telegram when enabled), re-checks, runs the argv with a fixed environment and journals each step. `onceroot` (user) only submits requests, lists cards and starts approvals that go through polkit. Pure logic lives in small internal packages tested on any OS; Linux-only parts sit behind build tags and run in a Linux container.

**Tech Stack:** Go 1.27, stdlib plus `golang.org/x/sys`; polkit `pkcheck`; systemd; Python 3 stdlib for the mutation script only.

**Spec:** `docs/superpowers/specs/2026-10-27-onceroot-design.md`

## Global Constraints

- Module `github.com/TAIPANBOX/onceroot`, `go 1.27`, MIT licence; ported files keep a header naming their origin (openwrt-mcp: MIT, Ian Williams and Yurii Kostiuk; rollcall: MIT, Yurii Kostiuk).
- go.mod may require only `golang.org/x/sys` (I15).
- Only `internal/runner` and `internal/polkit` import `os/exec`.
- Defaults (spec 6.3): TTL 10 min; open cards 3; 30 per hour per uid; pause 15 min after 3 rejections in a row; command time limit 30 min; PIN 6 to 8 digits, PBKDF2-HMAC-SHA256 200 000 iterations; 5 failed factor tries then 15 min lockout; TOTP RFC 6238, 6 digits, 30 s step, ±1 step.
- Root PATH for resolving: `/usr/local/sbin:/usr/local/bin:/usr/bin`. Command environment: `PATH` as above, `LANG=C.UTF-8`, `HOME=/root`, nothing else (I8).
- Socket `/run/onceroot/onceroot.sock`, mode 0660, group `onceroot`. Polkit action `org.taipanbox.onceroot.run`, `auth_admin` for allow_any, allow_inactive, allow_active (I13).
- Every new test runs red against the unfixed code first; the report names the failure.
- Card ids: 5 letters A-Z excluding I and O.
- Repository text, comments and docs in English; no quotes of the owner and no attribution in this repo (it will be public): decisions as `@decided 2026-10-27` paraphrases.
- Nothing is pushed or published; no remote.

## Review Focus

1. A command that waits for stdin or a TTY (`pacman -S` without `--noconfirm`): it must not hang; stdin is `/dev/null`, so it ends with the program's own error. Pinned in Task 12 (`TestRunnerStdinIsEmpty`).
2. Arguments with spaces, quotes, newlines or bidi marks: the card shows them unambiguously and the program receives them byte for byte. Pinned in Task 3 (`TestRenderQuotesAwkwardArgs`) and Task 12 (`TestRunnerPassesArgvVerbatim`).
3. A relative or missing `argv[0]` (`./x.sh`, `nosuchcmd`): refused with a reason before any card exists. Pinned in Task 9 (`TestResolveRefusesRelativeAndMissing`).
4. The agent gives up (CLI killed, MCP call cancelled) while its card is held: the card is withdrawn and can never run later. Pinned in Task 13 (`TestCardWithdrawnWhenClientDisconnects`).
5. A command that prints megabytes or never ends: output is streamed, never buffered whole, and the time limit kills the whole process group. Pinned in Task 12 (`TestRunnerStreamsLargeOutput`, `TestRunnerKillsProcessGroupOnTimeout`).

### Task 4: Rules, the built-in deny list and risk labels

**Interfaces:**
- Produces:
